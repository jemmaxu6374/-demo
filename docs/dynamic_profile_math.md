# 动态画像数学模型

> Phase 2 的能力画像从"静态一次抽取"升级为"持续吸收证据 + 随时间衰减"。本文档说明贝叶斯更新与指数衰减的具体公式、参数选择与边界情况。

## 一、核心观点

**每个员工的每项能力** 建模为一个独立的 **Beta(α, β) 分布**。分布有两个关键属性：

- **均值** `α/(α+β)`：映射为 level（1-5 整数）
- **密度集中度** `α+β`：代表证据累计量，值越大说明这个判断越稳

用 Beta 分布的好处是每次观测都是**共轭更新**（闭式解），无需近似。

## 二、更新公式

### 2.1 先验（冷启动）

```
α_0 = settings.bayes_alpha_init   # 默认 2.0
β_0 = settings.bayes_beta_init    # 默认 2.0
→ level_0 = 5 × α_0/(α_0+β_0) = 3.0（中性）
```

### 2.2 观测（事件吸收）

一次事件的归因输出 `(delta_level ∈ [-1, 1], confidence ∈ [0, 1])`：

```
magnitude = |delta_level| × confidence × k
            # k = settings.bayes_max_delta_per_event = 0.6

if delta_level ≥ 0:                      # 正向证据
    α += magnitude
else:                                    # 反例（如评审被打回）
    β += magnitude

α = max(α, 0.5)
β = max(β, 0.5)                          # 软下限防止退化

level = round(1 + 4 × α/(α+β), 3)
```

**k 的含义**：一次事件最多让 α 或 β 增加 0.6，避免单次极端证据（如 delta=1.0, conf=1.0）瞬间反转长期积累。

### 2.3 时间衰减

事件吸收前先对"上一个时间点"的 α, β 做指数衰减：

```
Δt_days = (event_ts - last_ts).total_seconds() / 86400
factor = max(exp(-λ × Δt_days), decay_floor_ratio)   # floor = 0.2
α' = α_prev × factor
β' = β_prev × factor
```

为什么同时缩 α 和 β？因为我们衰减的是"证据总量"而非均值；均值 α/(α+β) 保持不变，但后续新证据的相对权重被放大。

### 2.4 λ 的来源：按 decay_type 区分

| decay_type | λ | 物理意义 |
| --- | --- | --- |
| hard（硬技能 / 工具） | 1/365 | 1 年衰减到 e⁻¹ ≈ 37% |
| soft（软技能） | 1/1095 | 3 年（软技能稳定） |
| domain（领域知识） | 1/730 | 2 年（中等速率） |

λ 的合理性来自学习科学常识："不用就忘"：
- 写代码能力半年不碰就生疏
- 沟通能力、问题拆解这类 metaskill 几乎不衰退
- 业务知识介于两者之间

## 三、level 连续值 vs 整数

Phase 1 的 `CompetencyTag.level` 虽然对外展示是 1-5 整数，但内部按连续值存储（`TimelinePoint.level`）。UI 展示时取 `round()` 即可。

**为什么保留连续值**：
- 避免 level 在 3.0 和 4.0 之间不断跳跃造成视觉抖动
- 支持"微进步"可视化（3.2 → 3.4 → 3.7 也有意义）
- 与 α, β 浮点参数一致，减少精度损失

## 四、合理性检查

每次 `update_one` 后比较新 level 与上次 level：

```python
if abs(new_level - prev.level) > 2.0:
    logger.warning(...)
```

阈值设 2.0 的原因：在 k=0.6 的上限下，理论上单次最大 Δlevel ≈ 4 × 0.6/(total+0.6)，
当 total ≥ 2 时单次上限 < 0.92，远小于 2.0。触发 >2 的跳变必然是异常（数据错或 α/β 接近 0），可以报警。

## 五、数值稳定性

**问题**：α 或 β 衰减到很小（<0.5）时，下一次事件吸收会产生过大波动。

**方案**：
1. `α = max(α, 0.5)` / `β = max(β, 0.5)` 软下限
2. `decay_floor_ratio = 0.2` 硬下限衰减系数
3. 证据最大贡献 k = 0.6 上限

组合后，系统永远不会出现极端翻转。

## 六、与 Phase 1 静态画像的桥接

Phase 1 从简历/项目抽取出的静态 level_0 如何进入 Beta 分布？

```
α_0 = level_0               # 把 level 当作 α 的初始值
β_0 = 5 - level_0           # 补足到 α+β=5
# 于是 α/(α+β) = level_0/5 → level = 5 × level_0/5 = level_0 ✓
```

当前 v1.0 的 `base_competencies` 直接给 level，没有显式 α/β；Phase 2 在第一次收到该员工该能力的事件时，才实例化对应 Beta。

## 八、未来改进

- **多证据源融合**：同一时刻多个事件同时发生时，先合并再更新会更稳（当前是逐条吸收）
- **λ 自学习**：从历史"衰减→恢复"轨迹反推个性化 λ（当前是硬编码按 decay_type 分类）
- **置信度反馈**：员工点击"这条推荐不相关"可下调相关 competency 的 confidence
